## 🚀 Быстрый запуск (Loadstring)

Скопируйте и запустите одну строку в любом Luau-экзекуторе (Wave, Synapse, Solara, Arceus X, Delta, Fluxus, Real и др.):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ryomotik/MyAnimeMine-Autofarm/main/main.lua?v=" .. tostring(os.time()), true))()
```

Альтернативный запуск через универсальный загрузчик:
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ryomotik/MyAnimeMine-Autofarm/main/loader.lua", true))()
```

## 🔥 Что нового и исправлено в v2.1:

### 🌟 1. Исправлена прокачка дерева навыков (Skill Tree & Core)
- **Точный формат сетевых событий**: Событие `MineBuySkill` теперь передаёт правильные аргументы (`zoneKey, node.Family, node.Id`), а не только одиночный ID.
- **Прокачка ядра (Core Skills)**: Автоматически покупает и улучшает **Core Tap** (урон клика) и **Miner Slots** (дополнительные слоты персонажей вплоть до 8) через `MineUpgradeTap` и `MineBuyMinerSlot`.
- **Поддержка всех открытых зон**: Изучает доступные навыки по всем разблокированным зонам (`Z1`, `Z2`, `Z3`, `Z4` и т.д.) строго с проверкой наличия монет и открытости нод (`IsSkillNodeOpen`).
- **Кнопка мгновенной прокачки**: «🌟 Прокачать все доступные навыки сейчас» — моментально скупает все доступные ноды и уведомляет о количестве изученных навыков.

### ⛏️ 2. Авто-покупка и экипировка топовых кирок
- **Скупка кирок в магазине**: Проверяет реальное наличие кирок на складе (`MineStock.GetRemaining`), требования зоны и баланс монет, скупая наилучшие доступные кирки.
- **Выдача майнерам**: Находит самую мощную кирку в инвентаре и автоматически вооружает ею всех экипированных персонажей в слотах (`M1`..`M8`).

### 🗺️ 3. Авто-открытие новых зон (Auto Unlock Zones)
- Автоматически отслеживает стоимость открытия следующей зоны (`UnlockCost`).
- Как только на балансе накапливается нужная сумма монет, скрипт автоматически открывает следующую зону (`MineSelectZone`) и активирует её без необходимости ручного перехода.

### 🐾 4. Авто-сбор и экипировка лучших петов
- Забирает всех выпавших редких аниме-персонажей из сундука участка (`MineTakeChest`).
- Экипирует сильнейших персонажей в слоты (`MineEquipBest`).
- Живая телеметрия в меню: наглядно показывает имя героя, уровень, урон и выданную кирку для каждого слота.

### 🖱️ 5. Полноценный Автокликер курсора (Cursor Auto-Clicker)
- При наведении на руду спамит прямыми вызовами `fireclickdetector` по жиле (слайдер **CPS от 5 до 50**).
- Если курсор не на руде — непрерывно кликает `mouse1click()`.
- **Горячая клавиша `V`**: мгновенное переключение автокликера на лету.
- Реалистичная анимация взмаха кирки (`MineStrikeR15`).

### 💰 6. Авто-продажа (Free Auto-Sell)
- Автоматически телепортируется к торговцу `SellStand`, продаёт всю накопленную руду и возвращается на участок.
