## 🚀 Быстрый запуск (Loadstring)

Скопируйте и запустите одну строку в любом Luau-экзекуторе (Wave, Synapse, Solara, Arceus X, Delta, Fluxus, Real и др.):


## ✨ Основной функционал

### ⛏️ Автофарм руды (Auto Mine & Fast Clicker)
- **Мгновенное разбивание камней**: Автоматически сканирует все узлы (`Nodes`) на участке игрока и наносит быстрый урон через `NodeClick (ClickDetector)`.
- **Настраиваемая задержка**: Слайдер скорости кликов (от 0.01s до 0.5s) — выжимает максимум скорости без перегрузки клиента.
- **Авто-сбор сундука**: Регулярный автоматический забор накопленных ресурсов из сундука участка в инвентарь (`MineTakeChest`), чтобы сундук никогда не переполнялся.

### 💰 Умная авто-продажа (Free Auto-Sell)
- **Бесплатный обход платного геймпасса**: В игре авто-продажа доступна только за Robux. Наш скрипт реализует автономный цикл сбыта:
  1. Опустошает сундук участка в инвентарь.
  2. Телепортирует игрока к магазину руды (`SellStand`).
  3. Активирует стойку торговца, выбирает все предметы (`Select All`) и подтверждает продажу.
  4. Моментально возвращает игрока обратно на базу к руде.
- **Гибкий интервал**: Настраиваемый таймер сбыта (15 – 180 секунд).
- **Кнопка ручной продажи**: «Продать сейчас» для моментального вызова цикла в один клик.

### 🐾 Экипировка лучших петов (Equip Best Pets)
- **Постоянная оптимизация урона**: Автоматически вызывает нативный серверный ивент `MineEquipBest` по таймеру и при получении новых персонажей.
- **Авто-экипировка кирок**: Раздаёт наилучшие имеющиеся кирки всем экипированным майнерам в слотах (`MineEquipPickaxe`).

### ⚡ Авто-прокачка (Auto Upgrade)
- **Прокачка характеристик персонажей**: Автоматически прокачивает уровни майнеров:
  - 💥 **Damage** (Урон по руде)
  - 🏃 **Speed** (Скорость передвижения)
  - ⛏️ **MineSpeed** (Скорость добычи)
- **Дерево навыков (Skill Tree)**: Автоматически прокачивает доступные ноды дерева исследований текущей зоны (`MineBuySkill`).
- **Авто-покупка кирок**: Покупает следующий тир кирки в магазине при наличии достаточного количества монет (`MineBuyPickaxe`).

### 📊 Живая телеметрия и Fluent Amethyst UI
- **Статусная панель**: Отображение баланса монет ($), гемов (💎), номера текущей зоны и названия участка.
- **Интерфейс Fluent**: Премиальный дизайн с темой Amethyst, плавными анимациями, адаптивными слайдерами и горячей клавишей скрытия (`LeftControl`).

## ⚙️ Установка и использование

1. Зайдите в Roblox в плейс **«⛏️ Моя аниме-шахта»**.
2. Вставьте скрипт в поле экзекутора и нажмите **Execute**.
3. В открывшемся окне включите тумблеры:
   - `Авто-фарм руды`
   - `Авто-экипировка лучших петов`
   - `Авто-продажа`
   - `Авто-прокачка майнеров`
4. Сверните интерфейс нажатием клавиши `LeftControl` и наслаждайтесь фармом!
