## 🚀 Быстрый запуск (Loadstring)

Скопируйте и запустите одну строку в любом Luau-экзекуторе (Wave, Synapse, Solara, Arceus X, Delta, Fluxus, Real и др.):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ryomotik/MyAnimeMine-Autofarm/main/main.lua?v=" .. tostring(os.time()), true))()
```

Альтернативный запуск через локальный файл:
```lua
loadstring(readfile("C:/Users/abror/.gemini/antigravity/scratch/MyAnimeMine-Autofarm/main.lua"))()
```

## 🔥 Что нового и исправлено в v2.0:

### 🖱️ 1. Полноценный Автокликер курсора (Cursor Auto-Clicker)
- Добавлена отдельная вкладка **«Автокликер»** с поддержкой мыши и прицела.
- При наведении на любую рудную жилу спамит прямыми кликами `fireclickdetector` с бешеной скоростью (настраиваемый слайдер **CPS от 5 до 50**).
- Если курсор не на руде — непрерывно кликает `mouse1click()`.
- **Горячая клавиша `V`**: мгновенное включение/выключение автокликера в игре на лету.
- Воспроизводит настоящую визуальную анимацию взмаха кирки (`MineStrikeR15`).

### ⛏️ 2. Турбо-Автофарм Участка (Turbo Multi-Hit)
- **Умное определение участка**: Тройная система проверки (`OwnerUserId` ➔ `PlayerName` ➔ ближайший участок) исключает любые ошибки поиска.
- **Пакетные удары (Multi-Hit)**: Настраиваемый параметр «Ударов за такт» (по умолчанию 10 кликов за цикл) — камни с 1,000,000+ HP уничтожаются за пару секунд, а не ковыряются по одному клику.

### 🐾 3. Исправление экипировки лучших выпавших петов
- **Устранена главная причина бага**: При добыче руды новые редкие аниме-персонажи падают **в сундук участка**, а не сразу в инвентарь игрока.
- Скрипт теперь перед экипировкой автоматически **забирает всех выпавших персонажей из сундука** (`MineTakeChest`), и только затем вызывает оптимизацию слотов (`MineEquipBest`).
- Персонажи высшего тира (Gear 5 Luffy, Moon Fang Ichigo, King of Hell и др.) теперь гарантированно встают во все слоты `M1`..`M6`.
- Добавлена живая таблица экипированных майнеров прямо в меню: показывает каждого персонажа в слоте, его текущий уровень и точный урон.

### 💰 4. Авто-продажа (Free Auto-Sell)
- Стабильный автоматический цикл: забирает руду, телепортируется к торговцу `SellStand`, жмёт «Выбрать всё» и «Продать», и возвращается на участок.
- Во время продажи автофарм ставится на паузу, предотвращая десинхронизацию.

### ⚡ 5. Авто-прокачка
- Прокачка урона (`Damage`), скорости (`Speed`) и скорости копки (`MineSpeed`) всем майнерам в слотах.
- Автоматическая покупка доступных нод в дереве навыков (`Skill Tree`).
- Автоматическая покупка следующего уровня кирки в магазине.
